# To-Do List

A simple and responsive To-Do List web application built using **HTML, Bootstrap, and JavaScript**.

The application allows users to add tasks to a list and manage their daily tasks through a clean and simple interface.

## Features

* Add new tasks
* Display tasks in a list
* Simple and responsive user interface
* Bootstrap styling
* JavaScript-based task management
* Easy to use

## Technologies Used

* **HTML5** – Structure of the application
* **Bootstrap** – Styling and responsive layout
* **JavaScript** – Application functionality and DOM manipulation

## How to Run

Click on github-pages link under the deployments section

No additional installation or dependencies are required.


## Future Improvements

Possible improvements include:

* Mark tasks as completed
* Delete tasks
* Save tasks using Local Storage
* Add a dark mode
